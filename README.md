# SlimeBattle

TapTap 聚光灯 GameJam 项目。

## 游戏定位

《SlimeBattle》是一款俯视角 2D 群体引导、环境解题和护送策略游戏，包含轻度多周目 Meta、少量文本叙事和涌现式群体行为。

玩家扮演冒险者，但不能直接控制某一只史莱姆，也不能像即时战略游戏一样逐只下达命令。玩家只能通过放置食物、熔炉和障碍，利用地形、温度区域、事件和敌人，改变史莱姆的目标选择与行动路线。

单只史莱姆只会围绕进食、保暖和躲避危险行动；当多只史莱姆拥有相同目标时，它们会形成群体，自动排队、绕开障碍、互相推挤并参与战斗。玩家的核心能力不是控制角色，而是布置条件、观察涌现结果，并在行为偏离时继续调整环境。

## 玩家目标

玩家需要召集并保护最多 20 只史莱姆，护送运送中的武器穿过关卡并抵达终点，最终击败魔王哈斯哈斯。

本局失败条件为：

- 史莱姆全部死亡；
- 护送武器被摧毁。

护送武器抵达目标点并满足关卡条件后，当前关卡成功。击败魔王后进入后续场景或周目；失败后重新挑战当前或最近的场景。

## 核心玩法循环

```text
观察 → 判断 → 放置 → 涌现 → 意外 → 调整 → 达成或失败 → 观察
```

一次典型的游玩过程是：

1. 观察史莱姆、地形、引导源、敌人、守卫和护送武器。
2. 判断哪些环境因素可能改变史莱姆的目标与路线。
3. 放置或拆除食物、熔炉和障碍，建立一个行动条件。
4. 让史莱姆个体和群体自行行动、寻路、战斗或躲避。
5. 观察状态变化、群体形成、路线阻塞和战斗结果。
6. 根据行为偏差继续调整环境。
7. 护送武器抵达终点，或因史莱姆全灭、武器被摧毁而重新挑战。

## 史莱姆个体行为

史莱姆的基本需求是进食、保暖和躲避危险。它们会在可见目标和引导源之间选择行动目标；当存在多个引导源时通常随机选择，与当前状态对应的引导源优先。

当前策划确定的主要状态包括：

- **饥饿**：超过 90 秒没有进食后获得；攻击力降低 10%，之后每 10 秒有 20% 概率变为暴躁；进食后解除。
- **暴躁**：攻击力和移速提高 10%，但会攻击索敌范围内的人类；食物或熔炉等引导源可以帮助解除。
- **害怕**：移速提高 20%，暂时忽略引导源并自行逃跑，持续 10 秒。
- **寒冷**：移速和攻速降低 20%，攻击可以使敌人冻结 1 秒；接近温暖源或离开低温区域 20 秒后解除。
- **炙热**：生命值受到 30% 的损耗；攻击会使敌人燃烧，死亡时对半径 150px 内的敌人造成自身攻击力 15% 的范围伤害；接近低温区域或离开炎热区域 20 秒后解除。
- **战斗**：产生攻击意图并进入攻击范围后进入；一般会暂时忽略普通引导源，但饥饿或寒冷时仍可能优先满足对应需求。

冻结会暂停当前行动和状态。燃烧会持续 5 秒，每秒造成最大生命值 2% 的伤害；被冻结或进入低温区域时解除。暴击会使本次伤害翻倍。寒冷与炙热同时发生时相互抵消。

史莱姆的初始数值方向为攻击力 30、生命值 500、移速 200、攻速 1 秒、索敌半径约 300px；最终数值由配置资产和后续测试调整。

## 史莱姆群体行为

当至少 6 只史莱姆拥有同一个目标行为时，会自动形成史莱姆群体。

- 目标消失且 10 秒内没有新目标时群体解散。
- 群体人数少于 6 时立即解散。
- 同时最多存在 3 个群体。
- 相同目标的群体可以合并，但群体战斗时不进行普通合并。
- 群体成员仍可能被新的、更优先的目标吸引，改变目标后脱离群体。
- 只要群体中有成员接触到引导源，群体成员可以共同受到其影响。
- 史莱姆之间存在碰撞，会产生排队、推挤和窄路通行问题。

群体战斗时会随机采用防御型、均衡型或激进型策略，分别影响成员的生命、攻击、承伤和暴击倾向。群体移动还需要根据地形和可通过宽度决定整体移动、排队通过或解散行动。

## 环境元素和放置物

当前核心放置物包括：

- **食物**：吸引范围约 300px；史莱姆进食后食物消失，下一次食物放置有约 10 秒间隔。
- **熔炉**：吸引范围约 500px；核心区域半径约 50px，史莱姆在核心区域停留约 20 秒后获得炙热；熔炉可重复使用，拆除后约 20 秒才能重新放置。
- **障碍**：可以阻挡史莱姆、魔物和守卫，迫使史莱姆重新寻找路线；拆除后消失，不能直接复用。

当前图示给出的同时放置上限为 5。障碍数量还会随周目变化，一周目、二周目、三周目暂定分别为 8、5、3；“同时存在上限”和“本周目总可用数量”需要在配置规则中区分。

除放置物外，场景还可以提供温暖地区、低温地区、掉落物、固定事件和随机事件等引导源或触发条件。主干道路应保留足够的可行动空间，地形可以通过峡谷、沼泽、坑、窄路和城堡区域改变移动与决策。

## 敌人、守卫与护送武器

普通魔物在固定区域内移动，发现目标后进入追击和战斗；特殊魔物和 Boss 的行为后续扩展。魔物也会受到温度、障碍和其他场景元素影响。

守卫围绕护送武器行动，不会主动清理全场。只有处于战斗状态的魔物靠近武器时，守卫才会攻击；武器受到攻击后，守卫会停止当前行为并优先攻击距离最近的敌人。守卫也会受到障碍和环境状态影响。

普通守卫的初始数值方向为攻击力 100、生命值 1000、移速 300、攻速 1.2 秒；普通魔物的初始数值方向为攻击力 70、生命值 800、移速 300、攻速 1 秒。

## 游戏特色

- **群体引导**：玩家影响的是史莱姆群体，而不是直接操控角色。
- **涌现行为**：简单的个体规则组合后，可能产生复杂且难以完全预测的结果。
- **环境解题**：地形、窄路、障碍、陷阱和可放置物品共同构成解题空间。
- **意外与调整**：史莱姆没有绝对忠诚，原本的伙伴也可能因为环境变化成为新的麻烦。
- **轻快的冒险氛围**：采用俯视角 Q 版卡通风格，结合日式冒险和诙谐叙事。
- **护送与防守**：史莱姆负责推进和战斗，守卫保护护送武器，玩家负责调整环境和引导史莱姆。

## 当前设计中的世界

安宁镇最近并不安宁。魔王哈斯哈斯卷土重来，史莱姆大军也成为了威胁小镇的力量。

玩家选择与史莱姆相处，而不是直接命令它们。玩家将从安宁镇出发，经过峡谷和沼泽，最终进入魔王城堡，利用史莱姆群体的力量击败魔王，让小镇重新获得安宁。

当前策划中规划了以下场景方向：

1. 安宁镇
2. 峡谷
3. 沼泽
4. 魔王城堡

每个场景应围绕“观察环境—布置引导—让群体推进—处理意外”的循环设计。主干路径应保证多数史莱姆能够自由行动，分支、窄路、温度区域、障碍和事件用于制造路线选择与行为偏差。

击败魔王后进入下一场景或周目；多周目可以改变障碍数量、场景事件和关卡条件。随机事件库、完整道具表、特殊魔物和 Boss 行为仍需单独确认。

当前代码已经具备 GameRoot、LevelManager、LevelContext、ConfigRegistry、基础 Actors、Manager、基础 AI 决策/状态机和 Objective 失败数据；MovementSystem、StatusManager、MapManager、MechanismSystem、PlacementSystem、GuardManager、关卡 UI 和正式成功判定仍在建设中。当前 Level_test 主要用于验证菜单入口、配置读取、Actor 生成和目标初始化，尚不能代表完整玩法已经可玩。

当前开发环境：

- Unity `2022.3.62f2c1`
- URP 2D
- 输入方案：新版 Unity Input System Package
- 目标平台方向暂定为 Android；Android 版本、屏幕方向和分辨率尚未确定

当前正式游戏入口、Input System 的具体 Action Map/Binding、最终资源和首个可玩关卡仍在建设中。
