# SlimeBattle

TapTap 聚光灯 GameJam 项目。

## 游戏简介

《SlimeBattle》是一款俯视角 2D 群体引导游戏。

玩家扮演一名冒险者，但不能直接控制某一只史莱姆。玩家需要观察关卡环境，通过放置物品、调整机关和利用地形，影响史莱姆群体的行动，让它们自己完成关卡目标。

单只史莱姆看起来简单而迟钝，但当它们聚集在一起时，会形成自动排队、绕开障碍、互相推挤、攻击敌人等复杂的群体行为。玩家要做的不是下达每一步命令，而是设计条件，观察涌现出的结果，并在意外发生后继续调整。

## 核心玩法循环

```text
观察 → 判断 → 放置 → 涌现 → 意外 → 调整 → 达成或失败 → 观察
```

一次典型的游玩过程是：

1. 观察史莱姆、地形、机关、敌人和关卡目标。
2. 判断哪些环境因素可能改变史莱姆的行动。
3. 放置物品或调整机关，建立一个行动条件。
4. 让史莱姆群体自行行动。
5. 观察群体行为带来的结果，以及可能出现的意外。
6. 根据结果继续调整环境。
7. 达成关卡目标，或因史莱姆全部死亡、护送武器被摧毁等原因从当前场景重新尝试。

当前策划方案还提出：史莱姆总数暂定上限为 20 只；6 只及以上拥有同一目标行为时可能形成史莱姆群，最多同时存在 3 个群体。玩家可使用食物、障碍和熔炉改变环境，具体数量、冷却和组合效果仍待确认。

## 游戏特色

- **群体引导**：玩家影响的是史莱姆群体，而不是直接操控角色。
- **涌现行为**：简单的个体规则组合后，可能产生复杂且难以完全预测的结果。
- **环境解题**：地形、窄路、障碍、陷阱和可放置物品共同构成解题空间。
- **意外与调整**：史莱姆没有绝对忠诚，原本的伙伴也可能因为环境变化成为新的麻烦。
- **轻快的冒险氛围**：采用俯视角 Q 版卡通风格，结合日式冒险和诙谐叙事。
- **护送与防守**：守卫围绕护送武器行动，武器被摧毁或史莱姆全部死亡会导致本局失败。

## 当前设计中的世界

安宁镇最近并不安宁。魔王哈斯哈斯卷土重来，史莱姆大军也成为了威胁小镇的力量。

玩家选择与史莱姆相处，而不是直接命令它们。玩家将从安宁镇出发，经过峡谷和沼泽，最终进入魔王城堡，利用史莱姆群体的力量击败魔王，让小镇重新获得安宁。

当前架构设计中规划了以下场景方向：

1. 安宁镇
2. 峡谷
3. 沼泽
4. 魔王城堡

场景数量、关卡内容和 Meta/多周目范围仍以团队后续确认的版本为准。

## 当前玩法方向

现有设计重点包括：

- 史莱姆通过跳跃移动，跨越部分坑和矮墙；
- 史莱姆之间存在阻挡、推挤和窄路排队；
- 陷阱和机关可以影响史莱姆，即使史莱姆正在跳跃；
- 机关可以造成伤害、增殖或变种等效果；
- 多只史莱姆可以围攻同一个敌人；
- 镜头移开后，关卡中的其他区域仍然继续运行。
- 史莱姆的饥饿、暴躁、害怕、寒冷和炙热等状态会改变其移动、战斗或引导响应。

这些内容是当前设计与架构讨论中的玩法方向，最终规则和数值需要通过原型与试玩确认。

## 项目状态

项目当前处于 Unity 2D 初始阶段，正在建立团队规范、系统架构和第一个可验证的玩法闭环。

当前开发环境：

- Unity `2022.3.62f2c1`
- URP 2D
- 输入方案：新版 Unity Input System Package
- 目标平台方向暂定为 Android；Android 版本、屏幕方向和分辨率尚未确定

当前正式游戏入口、Input System 的具体 Action Map/Binding、最终资源和首个可玩关卡仍在建设中。
