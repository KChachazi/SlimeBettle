# 中文字体来源

`NotoSansCJKsc-Regular.otf` 来自 Noto CJK 官方仓库，采用 SIL Open Font License 1.1；完整许可随附在 `OFL.txt`。字体未改名、未裁切，保留原始字体元数据。

下载来源：

- https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
- https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE

UI 使用动态字体渲染，适用于运行时的中文结果与提示，不依赖本机安装字体。初次进入界面及动态字形纹理的移动端开销仍需设备测试。
