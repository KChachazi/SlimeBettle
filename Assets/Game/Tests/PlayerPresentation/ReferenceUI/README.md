# 彩色参考版式验证

这些 PNG 均来自实际 Unity Prefab 的渲染，参考用户提供的八张图片的版式，保留彩色森林、暖色纸签和史莱姆装饰。主界面及放置态见上级 `FirstLevelUI.png`、`FirstLevelUI-Placement.png`。

`EditMode.xml`、`PlayMode.xml` 为 Unity Test Runner 导出结果，仅将本机工作区路径前缀移除并整理缩进，测试结果与时间保持原样。测试场景使用 TEST_ONLY 数量、结果与机关后端，不是正式关卡的通过证据。

入口、数据边界与重建菜单见 `Assets/Game/UI/README.md`；本轮机器可读摘要见上级 `ReferenceUI-validation.json`。
